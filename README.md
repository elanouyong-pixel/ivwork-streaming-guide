# ivwork-streaming-guide

Guides and notes for discovering live streams on Twitch and Kick, 
maintained as part of the [ivwork.net](https://ivwork.net/) project.

## Guides

- [How channel rankings work](https://ivwork.net/rankings/channels/) — how we rank live channels by viewership and activity.
- [Trending games on Kick](https://ivwork.net/trends/kick-games/) — a daily snapshot of which games are pulling the most live viewers on Kick.
- [Game category map](https://ivwork.net/categories/) — the full category tree used across the site.

## Tools

- **Channel directory** — browse thousands of Twitch and Kick channels 
  with live status: https://ivwork.net/channels/
- **Multi-language UI** — the site is available in English, Japanese, 
  Korean and Chinese: https://ivwork.net/
